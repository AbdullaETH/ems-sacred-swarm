# EMS - Sacred Swarm (Священный Рой)

**EMS** = *Examen Machinarum Sacrum* - «священный рой машин». По-латыни *examen* значит и рой (пчёл), и проверку, взвешивание: рой агентов, который проверяет ваш проект.

Скилл для Claude Code: поэтапный аудит ваших проектов - что проект собой представляет сейчас, насколько он готов к продаже, где дыры в безопасности, кто конкуренты, что с рынком в вашем регионе и в мире, примерная стоимость и советы по продаже.

Дешёвые агенты Haiku только читают и собирают факты. Основная модель проверяет их, задаёт вопросы после каждой фазы и не жжёт лимиты. Критическая проблема безопасности блокирует всё, кроме её исправления.

## На какой вопрос отвечает

**Стрельнёт ли проект, для кого, по какой цене и что чинить первым.** Ответ сначала выводится на экран карточкой-вердиктом, потом сохраняется в файлы.

| Фаза | Что происходит |
|------|----------------|
| 0 Старт | Разрешения, страна и город, валюта (USD и ваша), режим (пошаговый или автопилот), пресет моделей, ваши честные цифры по затраченному времени. Печатается план запусков |
| 1 Состояние и готовность | Что проект собой представляет сегодня, оценка по рубрике из 8 критериев |
| 2 Гейт безопасности | Скан секретов и открытых мест, ручные проверки. Слабая - предупреждение, средняя - напоминание на каждом чекпоинте, критическая - блок |
| 3 Слабые места | Прямой список: что ужасно, чего нет, что в зачатке |
| 4 Ресёрч | S: мировая база + местная база + заменители. M: ваш город и регион вглубь, с официальной статистикой по аудитории. L: мировая картина. Арбитр сверяет уровни |
| 5 Аудитория и потенциал | Воронка аудитории снизу вверх, готовность платить, потенциальная выручка в год, пять критериев, вердикт *стрельнёт / при условии / не стрельнёт*, лестница стоимости |
| 5b Проверка спроса | Кого спросить, сценарий интервью, порог успеха, дешёвый тест |
| 6 Сборка | Карточка на экран, короткий отчёт; по запросу полный документ (md, txt, docx) |
| 7 Доработка | Приоритизированный план исправлений, бэклог идей |
| 8 Продажа | Кому, куда и как продавать, варианты цены внутри диапазона готовности платить, преза и бизнес-план |

У каждой цифры класс источника: **A** официальный, **B** пресса или вендор с датой, **C** агрегатор или сниппет. В расчёты идут только A и B.

## Требования и статус

- Claude Code с субагентами (скилл запускает агентов `Explore` на `haiku`, синтез на `sonnet`). Для ресёрча нужен веб-поиск. `gh` по желанию (видимость репозиториев).
- Статус: **v0.09**. v0.04 прогнан целиком на пяти реальных проектах; v0.06 перерабатывает анализ (сначала аудитория, вердикт, классы источников, вывод на экран). У скриптов есть регрессионные тесты в `tests/` (CI на Linux и Windows). Состязательной проверки на обход правил пока не было. Возможны шероховатости; issues и PR приветствуются.
- Пресеты моделей: economy (Haiku собирает, Sonnet сводит), balanced (Sonnet ещё на ресёрч L, аудиторию и вердикт), strong (везде Sonnet); любую роль можно переопределить.
- Агенты возвращают текст, файлы отчётов пишет основная модель в вашу папку отчётов.

## Быстрый старт

1. Установите скилл (ниже).
2. Скажите: *«запусти Священный Рой на `<путь к проекту>`»* или *«проверь мой проект перед продажей»*.
3. Ответьте на вопросы фазы 0 (папки, регион, язык, режим). После каждой фазы получаете короткую сводку, совет и вопрос; глубину ресёрча (S / M / L) выбираете вы.
4. Отчёты лежат в `<папка отчётов>/<проект>/`: `REPORT-SHORT.md`, `phases/`, `findings.json`, `ideas.md`.

Слова-триггеры: *Sacred Swarm, EMS, Examen Machinarum Sacrum, Священный Рой, Рой агентов, ЕМС, аудит проекта*.

## Установка

Склонируйте репозиторий и скопируйте папку скилла в каталог скиллов Claude Code:

```bash
cp -r skills/ems-sacred-swarm ~/.claude/skills/ems-sacred-swarm
```

На Windows: `skills\ems-sacred-swarm` → `%USERPROFILE%\.claude\skills\ems-sacred-swarm`. Затем скажите Claude: *«проведи аудит моего проекта»*, *«готов ли мой проект к продаже?»*.

Python 3.8+ желателен, но не обязателен: скрипты делают первый проход бесплатно. Без Python агент безопасности работает через Grep (медленнее и менее тщательно).

## Безопасность и экономия

- **Только чтение.** Скилл не пишет в проекты, не собирает и не запускает их. Отчёты лежат в отдельной папке. Доступ к GitHub - только `gh` на чтение; закрытые репозитории - только с вашего явного согласия.
- **Доказательство или молчание.** У каждого утверждения есть тег `[src: файл:строка]` или ссылка; `verify_evidence.py` проверяет, что такие строки существуют. Недоказуемое помечается `[UNVERIFIED]`.
- **Никаких выдуманных цифр.** Стоимость - всегда диапазон с допущениями.
- **Секреты маскируются** везде и не уходят ни агентам, ни в веб.
- **Экономия.** Сначала скрипты, агенты получают сжатые входные данные и лимиты слов и поисков, результаты кэшируются по отпечатку проекта, глубину ресёрча выбираете вы, перед каждой фазой показывается карточка нагрузки.
- **Гейт.** Критические находки (утёкшие ключи, закоммиченный `.env`, открытая админка, закрытый код в публичном репозитории) блокируют все фазы, кроме исправления. Удалить утёкший секрет мало: ключ нужно перевыпустить.

## Структура

```
skills/ems-sacred-swarm/
  SKILL.md          оркестратор (читает Claude)
  agents/           промпты ролей: scout, appraiser, critic, security, researcher, referee, sizer, potential, demand, collector, improver, sales-finance
  rubrics/          readiness, severity, potential, currency
  scripts/          inventory.py, scan_secrets.py, gate.py, verify_evidence.py, run_plan.py, export_report.py
  templates/        карточка на экран, короткий и полный отчёт, бэклог идей
tests/              регрессионные тесты скриптов (python -m unittest discover -s tests)
```

## Ограничения

- Haiku собирает факты, но не рассуждает глубоко. Оценку стоимости воспринимайте как ориентир, а не как экспертизу. Это не финансовая консультация.
- Сканер секретов работает по шаблонам: пропустит нестандартные форматы и даёт ложные срабатывания. Их разбирает агент безопасности.
- Качество веб-ресёрча зависит от того, что публично находится по вашей нише и региону.
