# EMS - Sacred Swarm (Священный Рой)

**EMS** = *Examen Machinarum Sacrum* - «священный рой машин». По-латыни *examen* значит и рой (пчёл), и проверку, взвешивание: рой агентов, который проверяет ваш проект.

Скилл для Claude Code: поэтапный аудит ваших проектов - что проект собой представляет сейчас, насколько он готов к продаже, где дыры в безопасности, кто конкуренты, что с рынком в вашем регионе и в мире, примерная стоимость и советы по продаже.

Дешёвые агенты Haiku только читают и собирают факты. Основная модель проверяет их, задаёт вопросы после каждой фазы и не жжёт лимиты. Критическая проблема безопасности блокирует всё, кроме её исправления.

## Что делает

| Фаза | Что происходит |
|------|----------------|
| 0 Старт | Один раз выдаёте разрешения: папки, GitHub (только чтение), веб-поиск, папка для отчётов. Выбираете регион и режим |
| 1 Состояние и готовность | Что проект собой представляет сегодня, оценка по рубрике из 8 критериев |
| 2 Гейт безопасности | Скан секретов и открытых мест, ручные проверки. Слабая проблема - предупреждение, средняя - напоминание на каждом чекпоинте, критическая - блок |
| 3 Слабые места | Прямой список: что ужасно, чего нет, что в зачатке |
| 4 Ресёрч | Уровень S (самые популярные), M (ваш город, страна, соседи), L (мировая картина на основе S и M) - уровень выбираете вы |
| 5 Стоимость | Диапазон стоимости сейчас и при 100% готовности, с допущениями и уверенностью |
| 6 Сборка | Короткая сводка, по запросу полный документ (md, txt, docx) |
| 7 Доработка | Приоритизированный план исправлений, бэклог идей |
| 8 Продажа | Кому, куда и как продавать, цена, преза и бизнес-план, разбор ваших готовых документов |

## Установка

Скопируйте папку скилла в каталог скиллов Claude Code:

```bash
cp -r skills/ems-sacred-swarm ~/.claude/skills/ems-sacred-swarm
```

На Windows: `skills\ems-sacred-swarm` → `%USERPROFILE%\.claude\skills\ems-sacred-swarm`. Затем скажите Claude: *«проведи аудит моего проекта»*, *«готов ли мой проект к продаже?»*.

Python 3.8+ желателен, но не обязателен: скрипты делают первый проход бесплатно. Без Python агент безопасности работает через Grep (медленнее и менее тщательно).

## Безопасность и экономия

- **Только чтение.** Скилл не пишет в проекты, не собирает и не запускает их. Отчёты лежат в отдельной папке. Доступ к GitHub - только `gh` на чтение; закрытые репозитории - только с вашего явного согласия.
- **Доказательство или молчание.** У каждого утверждения есть тег `[src: файл:строка]` или ссылка; `verify_evidence.py` проверяет, что такие строки существуют. Недоказуемое помечается `[UNVERIFIED]`.
- **Никаких выдуманных цифр.** Стоимость - всегда диапазон с допущениями.
- **Секреты маскируются** везде и не уходят ни агентам, ни в веб.
- **Экономия.** Сначала скрипты, агенты получают сжатые входные данные и лимиты слов и поисков, результаты кэшируются по отпечатку проекта, глубину ресёрча выбираете вы, перед каждой фазой показывается карточка нагрузки.
- **Гейт.** Критические находки (утёкшие ключи, закоммиченный `.env`, открытая админка, закрытый код в публичном репозитории) блокируют все фазы, кроме исправления. Удалить утёкший секрет мало: ключ нужно перевыпустить.

## Структура

```
skills/ems-sacred-swarm/
  SKILL.md          оркестратор (читает Claude)
  agents/           промпты ролей: scout, appraiser, critic, security, researcher, valuer, collector, improver, sales-finance
  rubrics/          readiness, severity, valuation
  scripts/          inventory.py, scan_secrets.py, gate.py, verify_evidence.py
  templates/        короткий и полный отчёт, бэклог идей
```

## Ограничения

- Haiku собирает факты, но не рассуждает глубоко. Оценку стоимости воспринимайте как ориентир, а не как экспертизу. Это не финансовая консультация.
- Сканер секретов работает по шаблонам: пропустит нестандартные форматы и даёт ложные срабатывания. Их разбирает агент безопасности.
- Качество веб-ресёрча зависит от того, что публично находится по вашей нише и региону.
