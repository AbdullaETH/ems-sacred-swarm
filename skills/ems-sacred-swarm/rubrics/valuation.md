# Valuation rubric

Output is always a **range** (Low / Base / High) for two moments: **now** and **at 100%** (MVP + demo + code complete).

## Methods

| Code | Method | Basis | Use when |
|------|--------|-------|----------|
| A | Cost to rebuild | estimated hours × regional rate; hours from scope and complexity (lines of code is a weak proxy, say so) | always available; a floor, not a price |
| B | Comparables | asking or sale prices of similar products, at least 2 sourced examples | listings or acquisition notes exist |
| C | Income potential | sourced market size × realistic share × margin | only with sourced market numbers and a defined customer |
| D | Strategic value | data, audience, brand, exclusive access (qualitative) | adjusts the range, never the base |

## Rules

1. At least two evidenced bases, otherwise write "insufficient basis" and give only method A with the caveat.
2. Pre-revenue products carry a discount against B and C; state the discount and why.
3. Write down every assumption (rate, hours, share). A reader must be able to re-run the numbers.
4. Confidence: **high** needs ≥2 independent sourced comparables; **medium** one comparable or a well-sourced market; **low** otherwise.
5. List the 3 factors that move the number most.
6. Currency: USD plus the local currency when a region is set; always add the date.
7. "At 100%" must state the remaining work, its cost, and what is assumed finished.
8. This is not financial advice; say so once.
